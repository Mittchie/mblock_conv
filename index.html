How to compile & upload in Arduino IDE

1

Install Makeblock Library

In Arduino IDE, open Sketch > Include Library > Manage Libraries... and install Makeblock.

2

Select Board & Port

Select Tools > Board > Arduino Mega or Mega 2560 (for Me Auriga) and pick your robot's COM port.

3

Upload to Robot

Connect your robot via USB cable, turn power ON, and click Upload (→).
